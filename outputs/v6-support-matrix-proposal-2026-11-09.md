# V6.0 支持矩阵范围提案（v6-support-matrix/1）

日期：2026-11-09｜状态：**范围已冻结**（用户于 2026-11-09 在对话中批准），`blocked_pending_scope` 解除｜依据：PRD r3 §4.5、B15–B25。
精确版本和模型标识在对应实施批次实测后补入，补入时升版，不覆写本文件。
冻结的只是验收范围，不批准源码实施、安装、迁移、Git 远端动作或发布。

冻结时遗留的两个确认项已于 2026-11-09 关闭：
1. Codex 内核接受 alpha（0.167.0-alpha.3.2），记录精确版本；alpha 升级后重新验收并升版矩阵。
2. WorkBuddy.app（com.tencent.workbuddy.mac，5.9.3）与 WorkBuddy AI.app（com.workbuddy.workbuddy-ai，5.9.4）是两个不同产品。矩阵只登记前者，后者标未验证。

## 2. 排除范围及理由

| 排除项 | 理由 | 对外口径 |
|---|---|---|
| E2 macOS x86_64、E3 Windows x86_64、E4 Linux x86_64、E5 Linux arm64 | 无真机，不能提供干净首装和升级的实际证据 | "未验证/待准备"，给手动接入路径，不宣传一键安装 |
| WorkBuddy AI.app（5.9.4）、Cursor、Grok、Kimi Code、DeepSeek Harness | 本机没有或未探测公开 hook 和规则导入；PRD 禁止用其他宿主的通过代替它们 | 入口能力标"未验证"；规则路径仍可使用 |

排除不等于不支持使用，只是 V6.0 发布验收不覆盖，也不得在发布说明里声称已支持。后续要加入，升版并补测，不覆写旧报告。

## 3. 必测集合（可机械枚举）

- **安装类（B15–B20）：** E1 ×（wheel×3.9、wheel×3.12、sdist×3.12、源码×3.12）×（首装 + 升级边 v5.2.7→V6.0）= 8 个组合。
- **入口类（B21–B24）：** 3 个 provider × 新会话、后续新目标、恢复、委派、授权生命周期快路径。
- **通用（B25）：** 冻结后不得删除失败组合；缺任一必需组合，就报该组合未验收，不宣称 V6.0 完整发布。

## 4. 仍需后补，不在本次批准范围

1. **模型档案：** 具体型号、量化、许可、磁盘/内存要求，要在 P2a 做影子评测后另行批准。没有它，P2a 的"就绪"无法验收。
2. **精确宿主版本：** 在实施时用实际版本补入。
3. **Python 组合（已定）：** wheel 路径测 3.9 和 3.12，sdist 与源码只测 3.12。所以安装类实际是 4 个组合乘首装/升级两种场景。
