## P1 节点总成本上限

- 初始值：单节点累计未缓存 input + output 约 2M tokens，含所有 developer 代次和 reviewer。
- 依据很薄：没有单节点实测成本。P0a 用 `scripts/supervisor_usage_audit.py` 跑出基线后重标。
- 触顶：监工先做全局诊断。仍需继续时，向用户申请提高预算，按新增授权处理。

## P4 降级继续的四条约束

1. **状态常驻可见。** `doctor` 和每次运行状态固定显示"本地压缩：未启用（原因）"，不显示就绪。
2. **数据驱动提醒。** 降级期间记录本可交给 Ollama 的长增量字节数，估算额外输入量。累计超过阈值才提醒，并给出一条继续安装的命令。同一次 run 最多提醒一次，不做每拍提醒。阈值待 P0a 基线后定。
3. **按原因区分：**
   - 用户拒绝：可选"不再提醒"，版本升级时再问一次。
   - 离线或下载中断：下次联网自动续装。
   - 资源不足：不再提醒。
4. **U8 不变。** 首装和升级仍必须走一遍初始化并给出选择，只是不阻止继续使用。
